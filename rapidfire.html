โจทย์แบบ "บอกมา 3 อย่าง" — 3 ประเทศที่อยากไป 3 อาหารที่ยอมกินไปตลอดชีวิต 3 ของที่จะหยิบถ้าบ้านไฟไหม้ ตอบให้ครบก่อนหมดเวลา ห้ามคิดนาน ยิ่งตอบเร็วยิ่งได้คำตอบจริงใจ

สุ่มโจทย์ขึ้นมา แล้วผลัดกันตอบคนละ 3 อย่างรอบวง ไม่มีเวลาบีบ

จบเกม!

วิธีเล่น · โหมดแข่งจับเวลา

  1. ใส่ชื่อผู้เล่น 2-10 คน เลือกเวลาต่อคน (5 / 10 / 15 วินาที) และจำนวนรอบ แล้วกดเริ่ม
  2. ระบบสุ่มโจทย์ขึ้นมา 1 ข้อ พร้อมบอกว่าถึงตาใคร — ยังไม่ต้องรีบตอบจนกว่าจะกด "เริ่มจับเวลา"
  3. พอกดเริ่ม เจ้าตัวต้องพูดคำตอบให้ครบ 3 อย่าง คนถือเครื่องแตะช่อง 1-2-3 ตามที่เขาตอบได้
  4. ครบ 3 ก่อนหมดเวลา = ได้ 1 แต้ม ถ้าหมดเวลาก่อน = ไม่ได้แต้ม (แต้มพิเศษ +1 ถ้าตอบครบภายในครึ่งเวลาแรก)
  5. ห้ามตอบซ้ำกับที่คนอื่นเพิ่งตอบในโจทย์เดียวกัน และห้ามตอบแบบกำกวมจนวงไม่ยอมรับ
  6. เล่นวนจนครบรอบ ใครแต้มเยอะสุดคือคนที่ปากไวที่สุดในวง

วิธีเล่น · โหมดชิล ๆ

  1. เลือกหมวดที่อยากคุย หรือปล่อยไว้ที่ "ทั้งหมด" แล้วกดสุ่มโจทย์
  2. อ่านออกเสียง แล้วผลัดกันตอบคนละ 3 อย่างวนไปรอบวง ไม่มีเวลาบีบ
  3. ตอบเสร็จแล้วชวนคุยต่อได้เลยว่าทำไมถึงเลือกอันนั้น — โจทย์เดียวคุยได้ยาว
  4. เหมาะกับตอนนั่งรถ รออาหาร หรือวงที่เพิ่งเจอกันครั้งแรก

กติกาเสริมสำหรับสายโหด

  1. ห้ามซ้ำทั้งเกม — คำตอบที่มีคนพูดไปแล้วในเกมนี้ ห้ามใครหยิบมาใช้อีก
  2. ลูกโซ่ — ตอบไม่ทัน ให้ส่งโจทย์เดิมต่อให้คนถัดไปทันที ใครตอบได้คนแรกเก็บแต้มไป
  3. ตัดสินด้วยวง — คำตอบไหนที่วงเห็นว่ามั่ว ให้โหวตตัดออก แล้วต้องหาใหม่ในเวลาที่เหลือ
  4. โหมด 5 วิ — เปิดใช้ตอนวงเริ่มคุ้นเกม จะได้คำตอบที่จริงใจกว่าเดิมมาก
ตอบไว ๆ ไม่ต้องคิดเยอะ คำตอบแรกที่โผล่ในหัวมักเป็นคำตอบที่จริงที่สุด ⚡
