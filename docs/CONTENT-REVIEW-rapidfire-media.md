## ตัวอย่างตามคำขอ

- 3 เพลงที่ชื่อมีคำว่า love — เพิ่มใหม่
- 3 เพลงที่ฟังตอนเศร้า — ย้ายและปรับข้อความจากเพลงที่เศร้าที่สุดเท่าที่เคยฟัง
- 3 เพลงที่จะเปิดในงานแต่งของตัวเอง — ย้ายและปรับข้อความจากเพลงที่ต้องมีในงานแต่ง

เพลงใหม่ผสมเงื่อนไขชื่อเพลงกับความชอบและสถานการณ์ หนังและซีรีส์ใหม่ใช้เงื่อนไขเนื้อเรื่อง ตัวละคร ฉาก และชื่อเรื่อง ตรวจแล้วทุกข้อมีตัวอย่างคำตอบได้อย่างน้อยสามรายการ ไม่กำหนดเฉลยตายตัวหรือเพิ่มเนื้อเพลง

## การตรวจซ้ำ

อ่านคลังเดิมครบ 800 ข้อและตรวจหมวดบันเทิงเดิม 100 ข้อเทียบกับโจทย์ใหม่ทุกข้อ ผ่านการตรวจความหมายอีกคน และไม่พบข้อความใหม่ซ้ำตรงหลัง normalize ข้ามคลังเกม ข้อที่มีหัวข้อร่วมกับเกมของโปรดเป็นคนละรูปแบบการเล่น จึงไม่ถือว่าเป็นโจทย์ซ้ำโดยอัตโนมัติ

ตัดโจทย์เดิมแปดคู่ที่ถามใกล้กัน โดยคงอีกข้อและย้ายเข้าหมวดที่ตรง:

- เพลงเปิดตอนขับรถกลางคืน
- หนังไทยที่ดีที่สุด/ประทับใจที่สุด
- หนังที่ดูแล้วอยากเที่ยว/ออกเดินทาง
- หนังที่เหมาะดูกับครอบครัว
- หนังตลกที่ขำที่สุด/ขำทุกครั้ง
- หนังที่คนชมเกินจริง/คนชอบแต่เราเฉย ๆ
- ซีรีส์ที่ดูจบภายในสองวัน/รวดเดียวจบ
- ซีรีส์ที่ทำให้นอนดึก/นอนดึกทั้งอาทิตย์

เพิ่มโจทย์ใหม่ผ่าน `add-entries.js --dry` แล้วเติมทีละ 20 ข้อและอ่านผล `check-content.js rapidfire --new 20` ทุกชุด ไม่มี ERROR หรือ REVIEW ของโจทย์ใหม่ หมวดใหม่มีทั้งปุ่มใน HTML และ `CAT_LABEL` ใน JavaScript ปุ่มหมวดใช้คีย์บอร์ดได้และมี `aria-pressed`

ระหว่างตรวจพบการกลับจากโหมดแข่งไปชิลหลังเปลี่ยนหมวดยังแสดงการ์ดเก่า แก้ให้สุ่มโจทย์ตามหมวดปัจจุบันเมื่อกลับโหมดชิล ส่วนการเปลี่ยนหมวดระหว่างจับเวลายังคงโจทย์ของรอบนั้นและใช้หมวดใหม่รอบถัดไป

## ผลตรวจชุดสุดท้าย

- `node scripts/check-content.js` ผ่านครบ 27 คลัง ไม่มี ERROR รายการ REVIEW เดิม 109 รายการตรงกับฐานก่อนแก้ทุกบรรทัด ไม่มีรายการใหม่จากงานนี้
- `node scripts/ship.js` ผ่าน สร้างป้ายหน้าแรกเป็น 852 โจทย์ และเลื่อนแคชจาก `party-games-v119` เป็น `party-games-v120`
- Playwright/Chromium ผ่าน 32/32: สุ่มโหมดชิลครบเพลง 42 หนัง 47 ซีรีส์ 30 และบันเทิงอื่น ๆ 33 ข้อโดยไม่หลุดหมวดหรือซ้ำก่อนครบรอบ ตัวอย่างเพลงตามคำขอครบทั้งสามข้อ
- ทดสอบ Enter/Space บนปุ่มหมวด โหมดแข่งเปลี่ยนหมวดโดยไม่ทับโจทย์ เวลา หรือช่องของรอบปัจจุบัน และใช้หมวดใหม่รอบถัดไป คะแนนรวมถูกต้อง กลับโหมดชิลแล้วโจทย์ตรงหมวด
- หน้าแรกแสดง 852 โจทย์จริงในเบราว์เซอร์ เปิดหน้าและสุ่มหมวดใหม่ทั้งสามได้หลังตัดเครือข่ายผ่าน service worker ไม่มี JavaScript error และไม่ล้นแนวนอนที่ความกว้าง 320, 390 และ 1280 พิกเซล
- การเปิด `file://` ใน Chrome ของ Cloud ถูกนโยบายผู้ดูแลบล็อก (`ERR_BLOCKED_BY_ADMINISTRATOR`) จึงไม่ได้อ้างว่าทดสอบเส้นทางนี้ผ่าน ไม่ได้เพิ่ม dependency หรือ build step ให้เว็บ การทดสอบข้างต้นใช้ไฟล์ static ผ่าน HTTP ในเครื่อง

สคริปต์ตรวจเบราว์เซอร์ logs ภาพหน้าจอ และรายการย้าย/ตัดซ้ำเก็บใน `/workspace/rapidfire-media-review/` ของงาน Cloud นี้
