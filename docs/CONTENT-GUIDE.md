# คู่มือเพิ่มโจทย์ประจำวัน

เอกสารนี้เขียนให้ AI agent ที่มารับหน้าที่ **เพิ่มโจทย์เข้าคลังเกมทุกวัน** อ่านจบแล้วทำงานได้เลย
โดยไม่ต้องถามอะไรเพิ่ม

---

## 1. งานหนึ่งวันหน้าตาเป็นแบบนี้

```bash
# 1) เลือกคลังที่จะเติม แล้วดูว่าตอนนี้มีอะไรอยู่บ้าง
node scripts/check-content.js flashquiz

# 2) เขียนโจทย์ใหม่ลงไฟล์ json ชั่วคราว (ดูโครงของแต่ละคลังในหัวข้อ 5)
#    เขียนทีละ 15-30 ข้อกำลังดี มากกว่านี้คุณภาพจะตก และตรวจซ้ำยาก

# 3) ต่อเข้าคลัง — สคริปต์จะปฏิเสธถ้าโครงผิด ซ้ำ หรือใช้หมวดที่หน้าเว็บไม่รู้จัก
node scripts/add-entries.js flashquiz /tmp/new.json --dry   # ลองดูก่อน
node scripts/add-entries.js flashquiz /tmp/new.json         # เขียนจริง

# 4) ตรวจ แล้ว "อ่าน REVIEW ทุกบรรทัดด้วยตาตัวเอง"
node scripts/check-content.js flashquiz --new 20

# 5) เตรียม commit (ตรวจทุกคลัง + สร้างป้ายจำนวนหน้าแรก + เลื่อนเลข cache)
node scripts/ship.js

# 6) commit แล้ว push
git add -A
git commit -m "เพิ่มโจทย์ Flash Quiz 20 ข้อ"
git push origin master
```

**ขั้นที่ 4 คือขั้นที่สำคัญที่สุด และเป็นขั้นเดียวที่เครื่องทำแทนไม่ได้**
`REVIEW` ไม่ใช่ error แต่คือรายการที่ต้องใช้คนตัดสิน อ่านให้ครบทุกบรรทัด

## 2. เกณฑ์คุณภาพของโจทย์

**ถูกต้องก่อนอย่างอื่น** ถ้าไม่แน่ใจข้อเท็จจริง ตัดข้อนั้นทิ้ง อย่าเดา
โจทย์ผิดข้อเดียวทำให้คนเล่นเถียงกันทั้งวง และทำให้เว็บเสียความน่าเชื่อถือ

- **ห้ามขัดกับข้อที่มีอยู่แล้ว** เคยพลาดมาแล้ว: เพิ่ม "จังหวัดใต้สุดของไทย → นราธิวาส"
  ทั้งที่ในคลังมีข้อเดิมตอบว่า "อำเภอเบตง จังหวัดยะลา" อยู่ ก่อนเพิ่มเรื่องที่คล้ายของเดิม
  ให้ `grep` หาคำสำคัญในไฟล์คลังก่อน
- **เลี่ยงข้อที่คำตอบเปลี่ยนตามเวลา** เช่น "ตอนนี้ใครเป็นนายก" "ตึกไหนสูงที่สุดในโลก"
  ถ้าจะใช้ ให้ระบุปีกำกับไว้ในคำถาม
- **เขียนให้คนไทยทั่วไปเล่นได้** ศัพท์เทคนิคเกินไปหรือเฉพาะกลุ่มเกินไปจะไม่สนุก
- **สั้น กระชับ อ่านออกเสียงได้ในลมหายใจเดียว** เพราะหลายเกมต้องอ่านให้เพื่อนฟัง
- **กระจายหมวด** อย่าเทลงหมวดเดียว 20 ข้อรวด ดูจำนวนต่อหมวดจาก `check-content.js` แล้วเติมหมวดที่บาง

### กฎเฉพาะของ Flash Quiz (เกมหลักของเว็บ)

Flash Quiz คือเกม "ตอบไว" ที่คนอ่านโจทย์แล้ววงต้องตะโกนคำตอบได้ทันที ไม่ใช่เกมความรู้ลึก

- **คำตอบยาวไม่เกิน 40 ตัวอักษร** (validator บังคับ) ถ้าคำตอบต้องอธิบายเป็นประโยค แปลว่าโจทย์ไม่เข้าเกมนี้
  ให้ย่อคำตอบเหลือคำสำคัญ แล้วย้ายรายละเอียดไปไว้ใน `explain`
- **ระดับความยาก: คนในวง 1 ใน 3 ควรตอบได้** โจทย์ที่ดีคือ "อ๋อ รู้ ๆ แต่นึกไม่ออก" ไม่ใช่ "ไม่เคยได้ยินเลย"
  ตัวอย่างที่กำลังดี: "แม่น้ำสายใดยาวที่สุดในโลก" "วง BTS มีสมาชิกกี่คน"
  ตัวอย่างที่ยากเกินเกมนี้: "ภูเขาใต้ทะเลยอดแบนเรียกว่าอะไร" "IBM 350 RAMAC ใช้จานแม่เหล็กกี่แผ่น"
- ผสมสัดส่วนราว **70% ทั่วไป / 30% ท้าทาย** ต่อชุด ถ้าเขียนออกมาแล้วยากทั้งชุด ให้กลับไปแก้
- เน้นเรื่องที่คนไทยคุยกันจริง: ไทย ๆ หนัง เพลง เกม กีฬา อาหาร มากกว่าเกร็ดประวัติศาสตร์ตะวันตกเชิงลึก

### เรื่องที่เว็บนี้วางตัวเป็นกลาง

- **การเมืองและดินแดน** — เกมต่อพรมแดนตั้งชื่อเฉพาะประเทศสมาชิก UN ส่วนดินแดนพิพาท
  เขตปกครองพิเศษ และแอนตาร์กติกา แสดงเป็นแผ่นดินไม่มีชื่อ ให้รักษาแนวนี้ในทุกคลัง
- **หลีกเลี่ยงโจทย์ที่ล้อเลียนบุคคลจริง ศาสนา หรือกลุ่มคนเฉพาะ**
- เกม `flirt` และ `tenbut` เล่นกับความสัมพันธ์ได้ แต่ให้อยู่ในระดับที่เล่นกับเพื่อนร่วมงานได้

### คำอธิบาย (`explain`) ที่ดี

คลังที่บังคับมีคำอธิบาย: `flashquiz` · `guessnumber` · `trivia`

- ยาวประมาณ 40–110 ตัวอักษร (validator บังคับขั้นต่ำ 15)
- **เพิ่มความรู้ ไม่ใช่พูดคำตอบซ้ำ** — "เพราะคำตอบคือดาวพุธ" ใช้ไม่ได้
- ใส่ตัวเลข บริบท หรือเกร็ดที่ทำให้คนอ่านแล้ว "อ๋อ"

```
ดี   ทฤษฎีนี้บอกว่าเวลาเดินช้าลงได้เมื่อเคลื่อนที่เร็วหรืออยู่ใกล้แรงโน้มถ่วงสูง
     ซึ่งดาวเทียม GPS ต้องชดเชยค่านี้จริง ๆ
ไม่ดี  ไอน์สไตน์เป็นผู้คิดค้นทฤษฎีสัมพัทธภาพ
```

## 3. วิธีหาโจทย์ซ้ำ (จุดที่พลาดบ่อยที่สุด)

การเทียบข้อความตรง ๆ จับได้แค่ซ้ำเป๊ะ ซึ่งเป็นส่วนน้อย ของจริงที่หลุดรอดคือ:

| แบบ | ตัวอย่างที่เคยหลุด |
|---|---|
| ถามกลับด้าน | "เกม Tetris มีเป้าหมายคืออะไร" ↔ "เกมใดที่ผู้เล่นต้องเรียงบล็อกให้เต็มแถว" |
| สลับคำถาม-คำตอบ | "Au คือธาตุใด" ↔ "สัญลักษณ์ทางเคมีของทองคำคืออะไร" |
| เขียนชื่อคนละแบบ | "เรือไททานิคอับปาง" ↔ "เรือไททานิกจมลง" · "นาร์วาฬ" ↔ "นาร์วาล" (หลุดมาแล้วจริง ๆ จากการเพิ่มคนละวัน) |
| ถามคนละมุมของเรื่องเดียวกัน | "ตัวละครหิมะในเรื่อง Frozen ชื่ออะไร" ↔ "แอนิเมชันเรื่องใดมีตัวละครชื่อโอลาฟ" |

**วิธีรับมือ** — validator ช่วยได้สองชั้น แต่ชั้นสุดท้ายต้องใช้คน

1. `add-entries.js` บล็อกข้อที่ซ้ำเป๊ะและเกือบเป๊ะ ตั้งแต่ก่อนเขียนลงไฟล์
2. `check-content.js` พ่น `REVIEW` สองแบบให้อ่าน
   - `อาจซ้ำกับ ...` — ตัดวรรคตอนและคำลงท้ายออกแล้วเหมือนกัน
   - `คำตอบ "..." ใช้ร่วมกัน N ข้อ` — **คำตอบซ้ำไม่ผิดเสมอไป** ประเทศ ศิลปิน หรือปีเดียวกัน
     ใช้ตอบหลายคำถามได้ตามปกติ ให้อ่านคู่นั้นแล้วตัดสินว่าเป็นคนละคำถามจริงหรือเปล่า
3. ก่อนเพิ่มหัวข้อที่รู้สึกว่าน่าจะเคยมี ให้ `grep` ก่อน **และ grep ทุกแบบสะกดของชื่อทับศัพท์**
   ไม่ใช่แค่แบบที่ตัวเองเขียน:
   ```bash
   grep -n "ไททานิก\|ไททานิค\|Titanic" data/flashquiz.js
   grep -n "นาร์วาฬ\|นาร์วาล\|narwhal" data/flashquiz.js
   ```
4. grep **คำตอบ** ด้วย ไม่ใช่แค่คำถาม เพราะโจทย์ที่ถามเรื่องเดียวกันจากคนละมุมมักมีคำตอบเดียวกัน:
   ```bash
   grep -n 'answer: "แคนาดา\|answer: "ประเทศแคนาดา' data/flashquiz.js
   ```

## 4. ข้อผิดพลาดที่เคยเกิดจริงในโปรเจกต์นี้

| อาการ | สาเหตุ | ทางแก้ |
|---|---|---|
| ไฟล์คลังพังทั้งไฟล์ ขึ้น `SyntaxError` | ข้อสุดท้ายของไฟล์เดิมไม่มีจุลภาคปิดท้าย พอต่อข้อใหม่เลยได้ `} { question:` | ใช้ `scripts/add-entries.js` เท่านั้น อย่าต่อท้ายเอง |
| เพิ่มโจทย์แล้วแต่หน้าแรกยังขึ้นเลขเก่า | ลืมรัน `build-game-counts.js` | `node scripts/ship.js` |
| deploy สำเร็จแต่คนเล่นไม่เห็นของใหม่ | ลืมเลื่อน `CACHE_VERSION` ใน `sw.js` service worker เลยเสิร์ฟไฟล์เก่า | `node scripts/ship.js` |
| กดปุ่มกรองหมวดแล้วจอว่าง | ใส่หมวดใหม่ในคลัง แต่ไม่ได้เพิ่มปุ่มใน html และชื่อหมวดใน js | validator จับให้แล้ว ตามไปแก้ทั้งสองที่ |
| ตัวอักษรภาษาอื่นหลุดเข้ามา | เคยมี `เดอะฟลैช` (สระเทวนาครี U+0948) ปนมา มองด้วยตาแทบไม่เห็น | validator เช็กช่วงอักขระให้ทุกครั้ง |
| ทายเลขแสดงผลเป็น "1945 ค.ศ." | ใส่ `unit: "ค.ศ."` ทั้งที่คำถามปีไม่ต้องมีหน่วย | ใช้ `unit: ""` สำหรับคำถามปี |

## 6. คลังที่ยังว่างและงานที่รออยู่

- **`triviaqa` ยังไม่มีคำอธิบาย** ทั้ง 309 ข้อ ต่างจาก `trivia` ที่มีครบ
  ฟิลด์ `explain` เปิดรับไว้แล้วและหน้าเว็บพร้อมแสดง — เป็นงานที่ทำต่อได้ทันที
- **หมวดที่ยังบางในแต่ละคลัง** ดูจากตารางหัวข้อ 5 แล้วเติมหมวดที่ตัวเลขน้อยกว่าเพื่อน
- **`bluff` มีแค่ 124 ข้อ** น้อยที่สุดในบรรดาคลังคำถาม และมีเงื่อนไขพิเศษว่า
  คำตอบต้องสั้นพอจะพูดออกเสียงและแต่งเลียนแบบได้ (validator บังคับไม่เกิน 45 ตัวอักษร)

## 7. สิ่งที่ห้ามทำ

- **ห้ามแตะ `data/worldmap.js`** เป็นไฟล์ที่สร้างจาก `scripts/build-worldmap.js`
  แก้มือแล้วจะหายตอนสร้างใหม่
- **ห้ามแตะ `data/game-counts.js`** สร้างอัตโนมัติเหมือนกัน
- **ห้ามเปิด pull request** เว้นแต่เจ้าของสั่ง งานปกติ commit ลง `master` ตรง ๆ
- **ห้ามใส่ชื่อรุ่นโมเดล AI** ลงใน commit message โค้ด หรือไฟล์ใด ๆ
- **ห้ามเพิ่ม dependency หรือ build step** เว็บนี้ต้องเปิดไฟล์ html ตรง ๆ แล้วเล่นได้เสมอ
