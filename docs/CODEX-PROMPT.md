# Prompt สำหรับ session เติมโจทย์ประจำวัน

ก๊อปทั้งบล็อกด้านล่างไปวางเป็นข้อความแรกของ session ใหม่
เปลี่ยนแค่ `<คลัง>` กับ `<จำนวน>` ให้ตรงกับที่อยากได้ในวันนั้น

---

## Prompt ประจำวัน (ใช้ซ้ำได้ทุกวัน)

```
งานวันนี้: เติมโจทย์เข้าคลังเกมของเว็บนี้ 1 คลัง

เริ่มจากอ่าน AGENTS.md และ docs/CONTENT-GUIDE.md ให้จบก่อน แล้วทำตามขั้นตอนในหัวข้อ 1
ของ CONTENT-GUIDE ตามลำดับ ห้ามข้ามขั้น

คลังที่จะเติมวันนี้: <คลัง>
จำนวน: <จำนวน> ข้อ

ข้อกำหนด:
- ตรวจก่อนว่าไม่ซ้ำกับของเดิม โดย grep คำสำคัญในไฟล์คลังก่อนเขียนแต่ละข้อ
- กระจายหมวดให้สมดุล ดูจำนวนต่อหมวดจาก node scripts/check-content.js <คลัง>
  แล้วเติมหมวดที่มีน้อยกว่าเพื่อนเป็นหลัก
- ต่อเข้าคลังด้วย node scripts/add-entries.js เท่านั้น ห้ามแก้ไฟล์ data/ ด้วยมือ
- หลังเพิ่มเสร็จ ให้รัน node scripts/check-content.js <คลัง> --new <จำนวน>
  แล้ว "อ่าน REVIEW ทุกบรรทัดด้วยตัวเอง" ถ้าเจอคู่ที่ซ้ำกันจริงให้ลบข้อใหม่ทิ้ง
  แล้วเขียนข้อใหม่มาแทนให้ครบจำนวน
- ปิดท้ายด้วย node scripts/ship.js แล้ว commit เป็นภาษาไทย push ขึ้น master

สรุปตอนจบให้บอกด้วยว่า เพิ่มไปกี่ข้อ หมวดไหนบ้าง เจอ REVIEW กี่คู่
และตัดสินใจกับแต่ละคู่ว่าอย่างไร
```

## ลำดับคลังที่แนะนำให้เติม

เรียงจากที่ควรทำก่อน คลังที่โจทย์น้อยเมื่อเทียบกับความถี่ที่คนเล่น

| ลำดับ | คลัง | ตอนนี้ | หมายเหตุ |
|---|---|---|---|
| 1 | `triviaqa` | 309 ข้อ ยังไม่มีคำอธิบายเลยสักข้อ | งานเติม `explain` ให้ของเดิม ไม่ใช่เพิ่มข้อใหม่ ดู prompt เฉพาะกิจข้างล่าง |
| 2 | `bluff` | 124 | น้อยที่สุดในบรรดาคลังคำถาม คำตอบต้องสั้นไม่เกิน 45 ตัวอักษร |
| 3 | `guessnumber` | 134 | โจทย์ตัวเลข ต้องมี `unit` และ `explain` ทุกข้อ |
| 4 | `flirt` | 199 | หมวด `friend` กับ `social` บางกว่าเพื่อน |
| 5 | `taxi` | 208 | มีแค่ 2 หมวด เพิ่มสถานที่ไทยได้อีกเยอะ |
| 6 | `flashquiz` | 659 | ใหญ่สุดแล้ว เติมเมื่อคลังอื่นตามทัน |

## Prompt เฉพาะกิจ: เติมคำอธิบายให้ triviaqa

```
งานวันนี้: เติมฟิลด์ explain ให้คลัง data/world-trivia-qa.js (WORLD_TRIVIA_QA)
ซึ่งตอนนี้ 309 ข้อยังไม่มีคำอธิบายเลยสักข้อ ทั้งที่ฟิลด์เปิดรับไว้แล้ว

อ่าน AGENTS.md และ docs/CONTENT-GUIDE.md ก่อน โดยเฉพาะหัวข้อ "คำอธิบายที่ดี"

ทำทีละ 30-40 ข้อต่อรอบ อย่าทำรวดเดียวทั้ง 309 ข้อ เพราะคุณภาพจะตก
แต่ละรอบให้:
1. อ่านโจทย์กับคำตอบให้เข้าใจก่อน ถ้าไม่แน่ใจว่าคำตอบถูกจริง ให้ทักไว้แทนที่จะแต่งคำอธิบายกลบ
2. เขียน explain ยาว 40-110 ตัวอักษร ที่ "เพิ่มความรู้" ไม่ใช่พูดคำตอบซ้ำ
3. รัน node scripts/check-content.js triviaqa แล้วดูว่าไม่มี ERROR
4. commit เป็นภาษาไทย บอกว่าทำถึงข้อที่เท่าไรแล้ว

หมายเหตุ: ฟิลด์ explain ของคลังนี้ยังเป็น optional อยู่ ถ้าเติมครบทั้ง 309 ข้อแล้ว
ให้ย้าย "explain" จาก optional ไป required ใน scripts/content-pools.js
เพื่อบังคับว่าข้อใหม่ต้องมีคำอธิบายเสมอ
```
