# ตรวจเกมทายธงชาติและทายประเทศจากรูปร่าง

สองเกมใช้คลังร่วม 164 ประเทศ เลือกแยกหกทวีป ตอบออกเสียงแล้วกดเฉลยหรือข้ามไปประเทศถัดไป

- ธงชาติเป็น SVG จากอินเทอร์เน็ตที่ตรวจรหัส Git SHA-1 ตรงต้นทางครบทุกไฟล์ พร้อม MIT และฐานข้อมูล ODbL ต้นฉบับ
- รูปทรงใช้ Natural Earth จาก WORLD_MAP เดิม ไม่แก้ข้อมูลต้นทาง แสดงประเทศเดี่ยวหันเหนือขึ้นและบอกส่วนแผ่นดินที่ใช้หลังเฉลย
- ข้อมูลต้นทางและสิทธิ์แยกตามภาพธง เรขาคณิต และฐานข้อมูลใน assets/country-quiz/CREDITS.md
- สร้างคลังผ่าน add-entries.js --dry --init และ --init; fetch-country-flags.js --check ผ่าน
- check-content.js ไม่มี ERROR; ship.js สร้างจำนวนหน้าแรกและเลื่อนแคชแล้ว
- Playwright/Chromium ผ่าน 35/35 รวมเฉลย เปลี่ยนทวีป ถุงสุ่ม รูปธงทุกไฟล์ รูปทรงครบคลัง ประเทศไทย คีย์บอร์ด จอเล็ก ภาพเสีย การโหลดช้า และออฟไลน์จริง
- ตรวจผ่าน GitHub Actions เนื่องจากเครื่อง Codex Cloud เริ่มไม่สำเร็จ
