# ตรวจเกมร้านสะดวกซื้อ ลื้อสะดวกใจ

เพิ่มเกมสองคนเครื่องเดียว เลือกสินค้าแล้วปิดคำตอบก่อนส่งเครื่องให้อีกคนทาย สลับบทบาททุกหนึ่งรอบและนับแต้มร่วมเมื่อทายตรงกัน

## คลังและภาพ

- 30 สถานการณ์ใน 6 หมวด หมวดละ 5 ข้อ และภาพประกอบสินค้า 36 ตัวเลือก หมวดละ 6 รายการ
- น้ำอัดลม ชาพร้อมดื่ม นมและนมถั่วเหลือง ขนมขบเคี้ยว บะหมี่ และไอศกรีม
- ภาพประกอบต้นฉบับพร้อมชื่อแบรนด์และเครดิตใน assets/convenience-store/CREDITS.md เก็บในเว็บเพื่อเล่นออฟไลน์
- ใช้หน่วยความจำของรอบเท่านั้น ล้างปุ่มและข้อความคำตอบก่อนส่งเครื่อง ไม่เก็บชื่อหรือคำตอบลง URL หรือ storage

## ผลตรวจ

- สร้างคลังผ่าน add-entries.js --dry --init และ --init ทั้งสองคลัง
- node scripts/check-content.js ผ่านครบทุกคลัง ไม่มี ERROR; node scripts/ship.js สร้างจำนวนหน้าแรกและเลื่อนแคชแล้ว
- Playwright/Chromium ผ่าน 50/50 ครอบคลุมคำตอบถูก/ผิด ส่งเครื่อง ความลับ กดติดกัน สลับบทบาท คีย์บอร์ด มือถือ รูปเสีย และออฟไลน์จริง
- รูป PNG คืนจากสำเนาต้นฉบับและตรวจ SHA-1 ee7451cacf0641650ef1c23160baef8b119db960 ตรงก่อนใช้
- ตรวจด้วย GitHub Actions บนสาขาทดสอบ เนื่องจากเครื่อง Codex Cloud เริ่มไม่สำเร็จ
