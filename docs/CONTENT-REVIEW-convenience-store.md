# ตรวจร้านสะดวกซื้อ ลื้อสะดวกใจ — เพิ่ม 100 สถานการณ์

เพิ่มคำถามความชอบจากประเทศที่จะไปเที่ยวหรือทำงาน อาหารตามสั่ง เครื่องเขียนสำหรับอวยพรงานแต่ง และสถานการณ์เลือกสิ่งที่ตรงใจในชีวิตประจำวัน

- โจทย์ 45 → 145 ข้อ (+100); ตัวเลือก 54 → 108 รายการ (+54); รวม 18 หมวด
- ประเทศ 20 ข้อ แบ่งเที่ยวและทำงานอย่างละ 10; อาหารตามสั่ง เครื่องเขียน ขนมไทย กาแฟ ของขวัญ ดอกไม้ กระเป๋า กิจกรรม หมวดละ 10
- ภาพใหม่ 54 ไฟล์: SVG วาดใหม่ 37 ธง MIT 6 และภาพอาหาร/ขนม CC 11 ภาพ พร้อมเครดิตรายรายการ
- สำเนาธงและภาพถ่ายตรงต้นฉบับใน repo ทุกไบต์ ตรวจ Git SHA-1 ก่อนคัดลอก และไม่แก้คลังอาหารหรือเกมประเทศเดิม
- โจทย์ใหม่ผ่านการเทียบข้อความและรูปแบบมาตรฐานกับคลังเดิม ไม่พบซ้ำ ตรวจเนื้อหาให้แต่ละข้อถามคนละบริบท
- ป้ายประเภทของหมวดทั่วไประบุเป็นประเภทตัวเลือก ไม่ใช้ชื่อแบรนด์สมมติ; หมวดสินค้าเดิมยังตรวจความหลากหลายแบรนด์
- คนที่ 1/2 สลับบทบาทตามเดิม ส่งเครื่องแล้วล้างตัวเลือกและข้อความเฉลยออกจาก DOM ไม่บันทึกคำตอบลง storage หรือ URL
- add-entries.js --dry และคำสั่งเพิ่มจริงผ่านทั้งสองคลัง; check-content.js ไม่มี ERROR; ship.js อัปเดตจำนวนและแคช
- Playwright/Chromium ผ่าน 136/136 รวมทุกหมวดใหม่ เลือก/ส่งเครื่อง/ทาย/เฉลย ความลับ คะแนน จอเล็ก ภาพ PNG/SVG/JPEG เสีย และออฟไลน์จริง
- ตรวจ XML ของ SVG ใหม่ 37 ไฟล์และเปิดภาพตัวเลือกทุกหมวดผ่านเบราว์เซอร์จริง
